# victorops Provider

Manage [VictorOps/Splunk OnCall](https://www.victorops.com) users, teams, escalation policies, routing keys and more.

Reece fork of [splunk/terraform-provider-victorops](https://github.com/splunk/terraform-provider-victorops), based on upstream PR #21.

Notes:

- The VictorOps API allows about 2 requests per second. The provider retries with exponential backoff on HTTP 429 and transient 5xx errors.
- `VO_REPLACEMENT_USERNAME` can be set instead of `replacement_user` on each `victorops_user`.

## Example Usage

```terraform
terraform {
  required_providers {
    victorops = {
      source = "reecetech/victorops"
    }
  }
}

provider "victorops" {
  api_id  = var.victorops_api_id  # or set VO_API_ID
  api_key = var.victorops_api_key # or set VO_API_KEY
}
```
